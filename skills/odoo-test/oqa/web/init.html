Cấu hình workspace

Một workspace là một hệ thống Odoo cần test: địa chỉ, các tài khoản và (nếu có) thư mục chứa file mà testcase nhắc đến. Mật khẩu được lưu trong Windows Credential Manager, không nằm trong file cấu hình.

Hệ thống

Profile (tài khoản dùng để test)

Thư mục tham chiếu (tùy chọn)

Thư mục chứa các file mà testcase nhắc tới (file import, file đính kèm). AI chỉ đọc những thư mục bạn khai báo ở đây.
